## Backup and restore drill

Run on 29 October 2026 against the development database (3 projects, 16 stored files, 6 snapshots):

1. `ENV_FILE=.env scripts/backup.sh <dir>` wrote `database.dump` (1.2 MB), `storage.tar.gz` (93 MB, including page previews), `manifest.txt`, and `SHA256SUMS`.
2. A new empty database `mne_fieldops_restore` and an empty storage directory were created.
3. `scripts/restore.sh` verified checksums, restored the dump, reported no pending migrations, and extracted storage.
4. `pnpm backup:verify --compare <source>` re-hashed all 16 files, re-checked all 6 snapshot hashes, compared every table's row count, and recomputed totals for the 3 working plans (for example CMH139 revision 8: 1,440 installer hours, peak 8): **OK**.
5. One restored file was then altered; `backup:verify` reported "checksum differs" and exited 1. The drill database and storage were deleted afterwards.
